# Xoài Phiêu Lưu

App vừa học vừa chơi cho bé trên máy tính bảng: chữ cái tập viết, lập trình robot Bíp, lật thẻ, hứng trứng, ban nhạc khủng long và nuôi Bé Cốm.

Mở app: https://hoangvnh0602.github.io/xoai-phieu-luu/

- iPad: mở bằng Safari → Chia sẻ → Thêm vào MH chính.
- Android: mở bằng Chrome → menu ⋮ → Cài đặt ứng dụng.

Tiến độ chơi chỉ lưu trên từng máy. Sao lưu/chuyển máy: góc bố mẹ (ổ khoá) → Tạo mã sao lưu / Khôi phục.
